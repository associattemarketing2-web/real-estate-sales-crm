# Lead Lifecycle

NEW LEAD → CONTACTED → QUALIFIED → PROJECT MATCHED → BROCHURE SHARED → SITE VISIT PLANNED → SITE VISIT DONE → NEGOTIATION → TOKEN → BOOKING → AGREEMENT → CLOSED

Alternate terminal/holding states: LOST, DORMANT, FUTURE FOLLOW-UP.

Every transition should record actor, timestamp, previous state and new state. The UI may simplify presentation, but the database must preserve history.

## Lead 360 sections
Basic profile → source/campaign → requirements → qualification → matched properties → communication history → activities → follow-ups → site visits → negotiation → booking.
