# Product Requirements

## Lead fields
Name, phone, email, city/location, preferred language, source, campaign, owner, status, temperature/intent, last interaction, next action and next-action date.

## Requirement fields
BHK, budget, preferred locations, property type, carpet area, possession timeline, purpose, launch/readiness preference, loan requirement, down payment and EMI comfort.

## Project fields
Developer, project name, location, RERA reference, possession target, land parcel, towers, configurations, amenities, connectivity, status and media.

## Reporting dimensions
Organization, salesperson, source, campaign, project, BHK, location, pipeline stage, visit outcome, booking and time period.

## Non-functional requirements
Secure multi-tenancy, responsive UI, auditable changes, predictable performance for normal CRM workloads, accessible forms, resilient webhook processing and clear error handling.
