# Property Matching

## Example requirement
3 BHK, up to ₹2.5 Cr, Kharadi/Viman Nagar, self-use, possession within 24 months.

## Matching model
Filter hard constraints first: availability, configuration, budget ceiling where applicable. Then score soft preferences such as location, carpet area, possession, purpose, amenities and project attributes.

Return ranked candidates with a fit percentage and explicit reasons, for example: “3 BHK match”, “within budget”, “preferred location”, “possession timeline fits”. Never present an unexplained AI score.

## Sales action
The salesperson can select projects/units and use **Share Shortlist** to generate a WhatsApp-ready summary. The shortlist must record which inventory was shown and when, so attribution and follow-up remain measurable.

## Inventory freshness
Availability and price must display `last_updated_at`. Stale inventory should be clearly marked and must not be represented as confirmed availability without a fresh check.
