# Sales Process

## Pipeline
NEW LEAD → CONTACTED → QUALIFIED → PROJECT MATCHED → SITE VISIT PLANNED → SITE VISIT DONE → NEGOTIATION → TOKEN → BOOKING → AGREEMENT → CLOSED.

## Required discipline
Every active opportunity has an owner, next action and next-action date. Overdue follow-ups are visible to the salesperson and manager. Site visits record date, attendees, project, outcome and next step. Negotiation records should be structured enough to report price/offer state without storing unnecessary free-text secrets.

## Booking
Booking should be a controlled state transition with unit, project, buyer/lead, amount/payment metadata and actor audit trail. Inventory availability must update safely and idempotently.
